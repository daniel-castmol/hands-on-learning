# Hands-On Learning

This repository documents my personal learning journey through various data engineering and data science courses. It contains my notes, lab work, homework assignments, and personal projects.

## Purpose

This is my learning workspace where I:
- Document class notes and key learnings
- Complete and track homework assignments
- Build hands-on labs and exercises
- Create personal projects based on course concepts

**Note:** This repository contains only my personal work, notes, and assignments. It does not include proprietary course materials or content that cannot be made public.

## Structure

Each course has its own directory with the following organization:

```
course-name/
├── README.md                  # Overview of the course
├── module-name/
│   ├── README.md             # Notes from classes and labs
│   ├── homework/             # Homework assignments
│   └── labs/                 # Lab exercises (if applicable)
```
