# Data Engineering Bootcamp - Community Edition

Personal notes, labs, and homework from the Data Engineering Bootcamp at DataExpert.io.

## Course Information

- **Institution:** [DataExpert.io](https://dataexpert.io)
- **Program:** Data Engineering Bootcamp - Community Edition
- **Instructor:** Zach Wilson
- **Duration:** Multi-week intensive bootcamp
- **Format:** Self-paced with community support

## Course Overview

This bootcamp covers the fundamentals of data engineering, including:
- Data modeling and dimensional modeling
- Batch data processing
- Data pipelines and orchestration
- Data quality and testing
- Modern data stack tools
- SQL and Python for data engineering

## Learning Approach

For each module, I:
1. Watch lectures and take detailed notes
2. Complete hands-on labs and exercises
3. Submit homework assignments
4. Build additional practice projects
5. Document key learnings and insights
